## 如何读「理解示例」栏目

每章（有实质技术内容时）增加了 **「理解示例（书中案例）」**：

1. **书中例子**：片名 / 示图号 / 版本 / 调度形态等，锚定原书（派生章节全文在 `source-derived/_chapter_full/`，分页 OCR 在 `txt/by-chapter/`）。  
2. **帮助理解**：这一条在证明什么方法或观点——先懂概念，再用例子「看见」概念。  
3. 建议顺序：**概念小节 → 理解示例 → 回原文图页对照 → 实践清单**。  
4. 分部扉页、纯序跋等源文无分镜范例的章，会标明 **「无书中范例可补」**。

## 统一学习结构

每章总结通常包含：

1. **本章定位** — 在全书中的功能  
2. **一句话概要**  
3. **核心观点 / 立场** — 作者思想  
4. **方法与技法 / 分节知识点** — 尽量覆盖原文 x.y 小节  
5. **理解示例（书中案例）** — 原书片例/图号/版本
6. **实践清单** — 拍前/读后自检  
6. **关键词**  
7. （如有）案例要证明什么、原文信息说明（空白插图页）
