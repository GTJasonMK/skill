# 引用架构与证据顺序

## 四层知识架构

1. [SKILL.md](../../SKILL.md)：触发、总流程、硬规则与输出合同。
2. `references/`：按未来任务重组的方法、路由、模板、案例和查表。
3. [内置章节笔记](../source/notes/)：39 个源单元的完整、逐节、带页码和案例的章节笔记，以及书籍地图和视觉索引。
4. [内置分页文本](../source/pages/by-chapter/) 与 [内置 PDF](../source/book.pdf)：393页 OCR 和最终视觉/文字证据。

方法参考不是第二套章节摘要；它只把跨章节知识重组为可执行方法。完整论证、逐页文本和图版证据都随 Skill 安装，不依赖父目录。

## 默认加载顺序

1. 由 [任务路由](task-router.md) 选择一个或多个任务参考。
2. 若需整体决策，加载 [决策核心](decision-core.md)。
3. 若需出处，先查 [来源覆盖](source-coverage-map.md)。
4. 若需完整上下文，打开映射到的内置章节笔记。
5. 若需精确文字，打开 `../source/pages/by-chapter/<单元>/PDF第NNN页.txt`，并与相邻页核对。
6. 若涉及图形、版面、专名字形或 OCR 可疑处，查看 [内置 PDF](../source/book.pdf)。

交付文件读取 [生产交付规范](production-deliverables.md)；涉及现行规范、高风险内容或受保护参与者时读取 [当代制作边界](contemporary-production-boundaries.md)。这两份属于 Skill 执行层，不改变原书来源覆盖状态。

## 证据等级

| 等级 | 证据 | 可支持的结论 | 不能单独支持 |
| --- | --- | --- | --- |
| A | PDF 原页/图版 | 精确构图、朝向、路径、透视线、画格文字、正式引文 | 无 |
| B | 分页 TXT + 相邻页 | 可搜索正文、术语、案例、可确认数值 | 图形关系、OCR 可疑专名 |
| C | 内置章节 Markdown | 完整方法解释、案例论证、页段导航 | 逐字引文、未看图的精确视觉断言 |
| D | Skill 方法参考 | 快速设计、审计、比较与路由 | 冒充作者逐字原文或完整章节替代物 |

## 引用写法

普通解释可写：`本书第10章（PDF 210–223页）把三人关系归纳为 A/L 形态，并允许 I 形态作为双人建构单位嵌入。`

精确定位写全：

- 源单元：第十章 三人对话场景的调度；
- PDF：210–223页；
- 笔记：[第十章完整笔记](../source/notes/20-第十章-三人对话场景的调度.md)；
- 原文：[第十章分页原文目录](../source/pages/by-chapter/20-第十章-三人对话场景的调度/)；
- 若问示图 10.3 或图 10-1～10-10：再查 PDF 原图。

不要制造不存在的逐字引文。若只能确认概念，使用转述并标明“方法提炼”。

## 历史与当代边界

本书中文版出版于 2010 年，正文还讨论更早的胶片、电视、MiniDV/HDV、软件、行业地址与价格。使用时分为三层：

- `作者原文`：保留当时语境，不用今天事实纠正后冒充原话；
- `Skill 提炼`：从原书方法抽出仍有效的决策规则；
- `当代补充`：涉及现行软件、传感器、稳定系统、虚拟制作、平台画幅或安全规范时，另查当前权威资料并明确标注。

## 已知证据风险

- PDF 第117页 OCR 有整行缺失，涉及一位独立电影人及《西卡柯七个人的归来》；不要猜补人名或缺句。
- 第3章 OCR 把《救生艇》识别为《教生艇》，并粘连《比弗利山警探 II》；正式片名以 PDF/权威片目复核。
- 图版低文字密度不等于空页。故事板构图、人物朝向、机位路径、透视与手写标注必须看 PDF。
- 焦距、宽高比、视角、尺寸和格数必须保留所用制式与历史语境。

## 可移植性与工具降级

- 核心任务只依赖本 Skill 内的 Markdown 参考和证据包，不调用其他 Skill。
- 实际生成位图故事板属于可选工具能力；没有图像工具时输出逐格画面规格、构图、动作、声音和验证清单。
- 无法视觉打开 PDF 时，只报告章节、PDF页、图号和正文可确认内容，并明确“尚未视觉复核”。
- 无联网或官方资料访问时，不回答当代设备、价格、平台规范或法规的确定值，只给需要向哪些官方来源核验的字段。
- 运行 `python scripts/verify_portability.py` 可检查证据数量、哈希、内部链接、绝对路径和越界依赖。
- [证据清单](../source/evidence-manifest.sha256) 对内置 PDF、41份笔记/索引和393个分页文本逐文件记录 SHA-256；更新证据后必须用 `--write-manifest` 重建并复验。
