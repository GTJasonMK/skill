读者朋友们，如果您听到有人引用 George Box 那句名言：“All models are wrong, but some are useful”，您就要就知道，又有哪个QR要开始为他那套在周二下午莫名其妙亏掉五百万刀的模型狡辩了。在quant圈，这句话真正的潜台词其实是：“反正所有模型都是错的，那我用一个最省事的错误模型，至少能让我赶上今天五点半的 happy hour。”如果您有一些 top prop 搬砖的朋友，您也许发现一个极其魔幻的黑色幽默：学术界在用数十张RTX Pro 6000炼丹，而掌握着几百亿美金的实盘底层逻辑往往糙得像个复旦附中高中生的开题报告。我们要理解为什么大家迷恋简单模型，得先看看一个高大上的 quant portfolio 到底是怎么运行的。一般故事是这么开始的： 老板花了一百万美金的 package，从Anthropic或者OAI挖来一个顶尖的 phd。这位天才不负众望，写了上万行极其华丽的 pytorch 代码，整了一个融合了 temporal transformer 和强化学习的超级深度学习架构。他用标准的 AdamW 优化器，在 A100 集群上烧了十万刀的credit。模型高调上线。由于这个 model 实在是太聪明、太非线性了，它在实盘里敏锐地捕捉到了 limit order book 里零点几毫秒的微观噪音。 它极度兴奋，在开盘前十分钟疯狂交易了五万次。下午收盘一算：paper alpha 收益：正两百万美金。付给 broker 的交易手续费和 slippage：负三百万美金。clearing house 乐开了花，你的 lp 当晚就给老板发了律师函。这时候，慌得要死的 pm 会一脚把这个 phd 踹开，转头对旁边那个拿着低保 base salary、每天在工位上摸鱼的 associate qr 说：“去，给老子整一个 ridge regression，只要做一件事：long apple，short tesla，然后根据历史 volatility 简单做个 vol-scale。”这个连 10 行 python 都不用的简单模型上线了。刚好赶上那周 tech sector 暴涨，模型躺赚了 5%。 于是，老板在季度 ppt 里写上：「我们利用先进的主动机器学习算法成功捕获了市场结构性红利」naive 的养老金 lp 们看完了 ppt 惊为天人，当场决定追加十个亿的 allocation。年底，这位写 ridge regression 的 lazy qr 拿到了两百万刀的 bonus，开开心心去 courchevel 坐直升机滑雪了。<img 里往往是个彻头彻尾的错误。市场里的真正 alpha，那些极短周期的非线性组合套利机会，在数学上全部缩在 kernel spectrum 那个微小的尾部（可以看我们近期的NS-NTK那篇工作）<img src="https://picx.zhimg.com/50/v2-bfbb3c438520317df308c808396f230c_720w.jpg?source=2c26e567" data-original="https://picx.zhimg.com/v2-bfbb3c438520317df308c808396f230c_r.jpg?source=2c26e567"/>线性模型或者树模型，在结构上就是个瞎子。它们唯一能看见的，是那些巨大特征值对应的平滑信号——也就是 macro beta。用 linear regression 去做量化，就像一个瞎子在通过用手摸画布的粗糙度来欣赏莫奈。他偶尔能猜对这幅画很大，但他永远看不到真正的景观。它们能赚钱，纯粹是因为画布正好在往他倒地的方向倾斜。一旦市场微观结构发生 regime shift，瞎子连怎么骨折的都不知道。那些在实盘里被 deep learning 伤害过的 pm 总是抱怨：“深度学习在金融里就是垃圾，除了过拟合就是拟合噪音。”老实说，这根本不是 data 的错，而是很多人在用一种 weak model 思维 在糟蹋 dl。把LLM或者CV那一套 adam/sgd 直接搬过来跑金融数据，完全不带脑子。在金融数据这种极低 snr 的死水里，这会产生两个极其荒谬的后果：一、在 low snr 下，deep neural network 的梯度协方差矩阵有个非常黑色幽默的数学特性：它的主导方向根本不指向真正的 predictive signal，而是完美指向对噪音最敏感的方向。 也就是说，你用标准 sgd 训练出来的、价值百万的 deep learning 模型，本质上是一个极其精密的、能以最快速度定位并撞向 market noise 的自杀式导弹。二、因为经典的 ntk 存在谱偏见，vanilla sgd 学习不同特征的速度是严重失衡的。它学那些简单的 beta 特征极快，但学习真正微观 alpha 特征（spectral tail）的速度，大概是每年一毫米。 而市场的 drift 速度是时速一百公里。 这相当于你用一架蒸汽机驱动的望远镜去追踪一架超音速隐形战机。 当你什么都没拍到的时候，你居然开始抱怨战机飞得不符合科学。其实要让 dl 在实盘里干翻那些简单模型，并不需要什么外星科技。你只需要在数学上稍微勤奋一点点，做一个 spectrally-aware 的优化。 既然尾部的 alpha 学习太慢，那我们就强行做一个 preconditioner，把整个 ntk 谱上所有特征方向的追踪速度全部拉平。让小特征值的学习速率不再 lagging。 同时，利用 online estimation，把那些指向梯度噪声敏感区的主导方向给 project 掉，别让模型去犯成千上万次蠢。在我们的测试里，这种调整过的模型在 crypto limit order book 和 nasdaq 股票上，哪怕扣掉最恶劣的手续费和一跳 slippage，出来的 out-of-sample pnl 依然能把那些 ridge regression 像垃圾一样清理掉。但话说回来，我很少看到有私募真的愿意花精力去重构这套底层的 optimization。 毕竟，要把这个数学原理给一个连GEMM都勉强看懂的 pm 解释清楚，实在是太难了。万一哪天碰上 black swan 亏了钱，写简单模型的 qr 可以理直气壮地说：“这是 systemic risk，全市场都亏了。” 而用复杂 dl 的你，大概率会被当成写 bug 的hacker直接开除。所以，大家继续假装 george box 的名言是真理，在 happy hour 里互相吹捧，顺便在各种社交媒体上写一些自我感动的科普。比如，我经常看到有些同行一本正经地论证：“金融数据 99% 全是噪音，猫有耳朵但股票没有，所以复杂模型注定要死，线性回归才是唯一救赎。” 这种人显然从来没有睁眼看世界。自己不会训非平稳网络，就只能把数据当成挡箭牌，靠贬低现代 dl 的表征学习能力来掩盖自己的技术瓶颈。更何况lazy learning的复杂模型适当处理也能爆杀linear。更离奇的是一些答案解释：“线性模型是真实关系的一阶泰勒展开，因为因变量和自变量之间存在恒定关联。短时预测本质上只要估对海森矩阵就行了，搞复杂的都是变量替换，不可微就超越了认知范围。”读到这种论调，我一时间不知道该先吐槽他们的金融常识，还是他们的数学水平。在连续漂移的非平稳市场里，去寻找所谓的恒定关系，无异于刻舟求剑；而在现代神经网络的 representation learning 面前，居然觉得不可微就无法解决，只能说明他们的认知范围确实窄得令人同情。不过这也挺好，正是因为市场上有这么多坚信“泰勒展开拯救世界”和“猫耳朵理论”的同行源源不断地提供流动性，我们这些可怜的小散户才能赚到钱。
