# 输出模板

按任务选择最小模板，不必把所有模板字段都展示给用户。

需要故事板逐格规格、平面机位图、animatic、长镜头提示表或生产镜头表时，使用 [生产交付规范](production-deliverables.md)，不要把本文件的回答模板冒充已确认生产文件。涉及高风险内容或现行规格时，同时读取 [当代制作边界](contemporary-production-boundaries.md)。

## 概念解释

```markdown
结论：一句话定义及它解决的问题。

工作原理：
- 它怎样改变观众的信息、空间、时间或认同。
- 适用条件。
- 与易混概念的区别。

设计规则：3–7 条可执行规则。

失败模式：常见误用及修正。

例子与来源：案例证明什么；章节、PDF 页；是否需要看图。
```

## 场景镜头设计

```markdown
### 戏剧—视觉命题
[关系从 A 到 B；观众跟随谁；转折何时被看见]

### 假设与约束
[场地、人物、时长、画幅、器材；未提供项的低风险假设]

### 节拍与观众认知
| 节拍 | 人物目标/变化 | 观众知道什么 | 注意中心 | 视觉策略 |

### 空间与轴线
[人物位置、动作范围、主轴、基本观看方向、新轴/越轴策略]

### 逐镜方案
| # | 画面与景别 | 主体/动作 | 机位/角度/运动 | 声音与切点 | 时长/节奏 | 轴线/视点 | 功能 | 级别 | 待确认 |

级别使用：必拍 / 编辑弹性 / 可选强化。

### 排练与拍摄
[走位动机、运动起停、焦点/遮挡、演员与掌机协作、连续性、安全]

### 降级方案
[复杂镜头失败时，怎样保持同一戏剧命题]

### 自检
[空间、时间、认同、反应、可剪性、成本和证据边界]
```

交付前在标题附近标记：`概念方案`、`导演工作稿`、`技术预演稿` 或 `已确认生产文件`。除非用户提供了实际测量、测试和部门确认，不得使用最后一种状态。

## 镜头方案审计

```markdown
结论：[可执行 / 需修改 / 存在不可拍或不可剪风险]

### 阻断问题
1. [位置/镜头号] — 证据 — 后果 — 最小修正。

### 重要表达问题
1. [信息、视点、节奏、反应、构图或运动动机]。

### 已成立的结构
[哪些设计应保留，说明其功能，不作泛泛表扬]

### 建议后的最小镜头链
[只在用户要求修改时给出]

### 来源与待验证项
[章节/PDF；需勘景、排练、镜头测试或看原图的内容]
```

审计顺序固定为：不可拍/不可剪 → 无意混乱 → 戏剧错位 → 执行效率 → 风格偏好。风格不同不是错误。
