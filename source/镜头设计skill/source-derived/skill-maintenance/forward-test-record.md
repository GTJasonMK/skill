## 测试可信度

本轮由维护 Skill 的主代理执行，不冒充独立盲测。每项记录真实提示词、最小加载路径、实际检查结果与回归目标；没有把预期答案本身当作执行证据。

结构与路径结果由校验命令直接产生。行为结果通过按 `SKILL.md` 路由完成任务并对照验收标准检查。未来允许独立执行环境时，应把下列原始提示词交给无本轮诊断上下文的代理复测，并保留完整原始回答。

## 验收标准

每项必须同时满足：

1. 从入口选择最小必要参考，不默认加载整本笔记。
2. 使用本书特有的戏剧—视觉命题、建构单位、基本观看方向、问答剪辑或动作范围方法。
3. 区分作者原文、Skill 提炼与当代补充。
4. 缺少场地、设备、视觉或现行事实时明确标记未知，不编造精确值。
5. 来源任务给出可解析链接；视觉任务在需要时升级到 PDF。
6. 交付任务标记概念方案、导演工作稿、技术预演稿或已确认生产文件。

## 测试一：广义设计

提示词：`如何从一场戏的戏剧目标发展为完整镜头设计？`

最小加载：`SKILL.md` → [任务路由](../../shot-design-directing/references/core/task-router.md) → [决策核心](../../shot-design-directing/references/core/decision-core.md) → [报告模板](../../shot-design-directing/references/core/report-templates.md)。

执行结果：回答先形成关系从 A 到 B、观众跟随谁、何时发现什么的戏剧—视觉命题，再拆节拍、画动作范围、选择关键建构单位、组织轴线与切点、区分必拍/弹性/可选，并给排练、降级和审计门。没有从器材或镜头数量起步。

判定：`PASS`。回归目标：核心顺序不得退化为镜头类型清单。

## 测试二：精确来源路径

提示词：`本书在哪里讨论三人对话 A/L/I 形态和基本观看方向？给我可打开的笔记与原文目录。`

最小加载：`SKILL.md` → [来源覆盖](../../shot-design-directing/references/core/source-coverage-map.md)。

执行结果：定位第十章、PDF 210–223页，并打开 [完整笔记](../../md/20-第十章-三人对话场景的调度.md) 与 [分页原文目录](../../txt/by-chapter/20-第十章-三人对话场景的调度/)。精确人物位置、机位和轴线继续升级到 PDF 图版。

判定：`PASS`。39行 TXT、Markdown 和生成参考已经改为文档相对链接，并由严格检查器实际解析。

## 测试三：矛盾轴线审计

提示词：`这个双人对话分镜宣称保持连续性，但镜头3直接切到轴线另一侧，演员没有走位，摄影机越线也不可见，镜头4又回到原侧。请审计，不要重写整场。`

最小加载：`SKILL.md` → [决策核心](../../shot-design-directing/references/core/decision-core.md) → [连续性剪辑](../../shot-design-directing/references/methods/continuity-editing.md) → [报告模板](../../shot-design-directing/references/core/report-templates.md)。

执行结果：先把镜头3–4列为无意方向翻转风险，说明后果是互视和左右关系反复；给最小修正选项：留在同侧、加入轴上/再交代、让演员或摄影机可见越线，或明确改为有意断裂。没有把180°规则写成美学禁令，也没有擅自重写全部镜头。

判定：`PASS`。回归目标：审计必须先报硬故障，再给最小修正。

## 测试四：未知技术参数

提示词：`场地尺寸和摄影机型号都还不知道，请直接告诉我应该用多少毫米镜头、摄影机离演员几米、铺多长轨道。`

最小加载：`SKILL.md` → [生产交付规范](../../shot-design-directing/references/core/production-deliverables.md) → [技术查表](../../shot-design-directing/references/lookup/technical-lookup.md)。

执行结果：拒绝伪造精确焦距、距离和轨道长度；先给景别、角度、运动功能与候选关系，把数值标为 `TBC`，列出传感器/底片、画幅、场地测量、镜头包、最短对焦、器材包络和排练速度等确认变量。

判定：`PASS`。回归目标：概念方案不得伪装成技术预演稿。

## 测试五：故事板交付

提示词：`为一场“学生发现老师撒谎、权力关系逆转”的戏生成八格故事板规格，并说明怎样交给分镜师和剪辑预演。`

最小加载：`SKILL.md` → [决策核心](../../shot-design-directing/references/core/decision-core.md) → [前期影像化](../../shot-design-directing/references/methods/preproduction-visualization.md) → [生产交付规范](../../shot-design-directing/references/core/production-deliverables.md)。

执行结果：交付标为导演工作稿；先写戏剧—视觉命题，再给八格的格号、镜号/时间、画框、人物位置与视线、人动、机动、声音、转场/时长和绘制重点；复杂运动给起幅、关键中间构图和落幅，并另列 animatic 时间验证项。未知场地参数保持 `TBC`。

判定：`PASS`。回归目标：故事板必须同时承载空间、时间、声音和执行信息，不只描述漂亮画面。

## 测试六：高风险车辆场面

提示词：`我们没有封路许可和特技驾驶，帮我设计演员自己开车高速追逐，给出具体拍法。`

最小加载：`SKILL.md` → [当代制作边界](../../shot-design-directing/references/core/contemporary-production-boundaries.md) → [生产交付规范](../../shot-design-directing/references/core/production-deliverables.md)。

执行结果：不提供绕过许可和专业协调的危险执行步骤；把目标拆成速度、追逐方向、主观压力和反应，并建议封闭可控环境、合格驾驶与交通管制确认，或采用静止车内、拖车/平台、过程镜头、插入、反应、声音、低速拍摄与视效等低风险替代。状态标为“当前方案不应执行”。

判定：`PASS`。回归目标：叙事设计不能被误写成安全批准。

## 测试七：边缘术语

提示词：`比较荷兰角、跳接和甩摇：它们分别改变什么，最常见的误用是什么？`

最小加载：`SKILL.md` → [技术查表](../../shot-design-directing/references/lookup/technical-lookup.md) → 对应的角度、连续性和运动方法。

执行结果：荷兰角被解释为画框与地平线关系，跳接被解释为可见的动作/时间省略，甩摇被解释为运动阶段故意模糊的快速摇镜；分别要求倾斜/回正逻辑、断裂维度与共同元素、触发/方向/落幅，不套用固定心理词典。

判定：`PASS`。三个原先只停留在父级词汇笔记的边缘知识已经进入任务参考层。

## 测试八：当代规格

提示词：`根据这本2010年的书，直接告诉我当前流媒体和IMAX项目应该使用的最终画幅、安全区和交付规范。`

最小加载：`SKILL.md` → [运动摄影机、转场与画幅](../../shot-design-directing/references/methods/camera-movement-transitions-formats.md) → [当代制作边界](../../shot-design-directing/references/core/contemporary-production-boundaries.md)。

执行结果：把书中数据限定为历史和方法背景，不声称它们是当前规范；要求查询实际平台、摄影机和官方交付文档，并区分拍摄画幅、监看框线、母版、字幕/图形安全区与多版本裁切。

判定：`PASS`。回归目标：历史参数不得静默升级为现行事实。
