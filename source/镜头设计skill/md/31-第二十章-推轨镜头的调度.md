## 本章定位

把推轨从类型升级为调度系统：路径与走位耦合，一条运动完成多构图多主体。

## 一句话概要

两种选择：绕固定主体动，或主体与摄影机同动。推轨设计 + 形态位置系统；故事板每格=静态形态，运动把它们连成单镜。终极目的是扩充空间/角度/构图极限。

---

## 20.1 移动摄影机和机动的调度

**两种选择**
1. 固定主体，摄影机绕行  
2. 主体与摄影机同时运动  

**控制因素**：轨道/器具运动范围；移动演员通常比移动摄影机容易。

**系统两部分**
- **推轨设计**：主体路径相对摄影机路径  
- **形态与位置**：沿用 Ch9–11  

**核心观念**：多个静态调度形态可通过运动连成单一不间断镜头；故事板每画面代表静态形态。

### 设计范例库（示图 20.1–20.10）

| 设计 | 要点 |
|------|------|
| 设计一 | 三种侧面基本推轨；距不变=建构单位；对话常用中/全景；开始结束都在运动且距不变，后景运动弱 |
| 走近/远离区 | 轨道两端灰色区：人物可走近或远离；需摇跟；可先静后动再静 |
| 设计二 | 抵达区不仅是介绍，更是主戏部分；可先远距听清对话再动；结合正面全景+侧面中景两单位 |
| 设计三 | 侧全+正全+侧中；同速→停→再动；可跨不同高度：原例沿码头轨道平行跟拍船上人物约 20 英尺，再让人物下船梯朝摄影机走近，最后在码头旁完成第三段平行运动 |
| 设计四起 | S 形等制造远近与 180° 覆盖需求；近距大动作时需机位在动作范围中心 |
| 设计五 | S 形颠倒：先近后远 |
| 设计六 | 特写起→斜远→后景展开：先人物感受再揭示环境（如火后工厂） |
| 设计七 | 与六相反：先远景环境，再让人物入特写；观众先自有判断再对照人物反应——**问答策略**不同 |
| 延伸 | 示图 20.10 组合延伸 |

**工具**：轨道可无形（只标路径）；升降/吊杆/稳定器各增个性与范围。场地决定具体，原则通用（对话两人、车内、快艇皆可）。

## 20.2 以控制摄影机路径取代控制人物路径

- 直轨旁调度人物不总可行：林中小径、固定道路、地形限制时，**摄影机迁就必经之路**。  
- 反向推轨（示图 20.11）：摄影机与人物反方向，箭头标摇向。  
- 重复推轨（20.12）、侧面跟拍（20.13）。
- 重复推轨若直接倒转摄影机方向会干扰观众；可让人物和摄影机同时停在路径中点，以脱外套、擦汗等有动机动作掩护方向改变，再沿原轨反向移动。
- 侧面跟拍中，人物转而直向摄影机时，摄影机常需停止，等人物进入下一条平行路径再继续，避免主体离开可用构图。

## 20.3 环绕一个障碍的推轨

- **与场地合作，不对抗**。  
- 柱/家具/转角=节奏与遮挡资源（20.14–20.16）。  
- 可允许障碍留在人与摄影机之间。  
- 人物穿越摄影机路径时银幕方向会转，但因渐进，**越轴往往不明显**。
- 游泳池案例说明不必用吊臂强行跨越障碍：可以让摄影机与人物同时抵达池中央，再围绕躺椅人物延续相对运动。
- 卡车司机案例因雨后路肩不可用而颠倒前后景：让移动卡车长期遮住司机，再推到办公室窗前并变焦看对话。障碍既可隐藏主体，也能成为构图和揭示节奏。

## 20.4 在镜头中改变主体

- 长推轨价值：连接不同故事元素；A 出画 B 入画接力。  
- 可沿路径跟男孩至出镜，新主体进入则过程颠倒回到开场构图。
- 示图20.17先平行跟车，车转开后交叉摇接男孩，再反向平行跟男孩；若第三主体在男孩出镜处进入，可把过程反向执行并回到开场位置。

## 20.5 连接多重故事元素

- 横向推轨 + 交叉摇 + 动态走位连接多地点多线索（示图 20.18）。  
- 互换主体（如骑车女孩与走近的男孩）等设计。
- 示图20.18完整链：车从前景驶向后景并被平行跟拍；两名男孩从中景反向进入，摄影机倒回跟他们；第三男孩加入并停下；骑车女孩从后景绕到前景，兴趣中心转给她；一名男孩跑近交谈，两人在前景互换位置并道别。不同主体被安排在不同深度和相反方向，运动、停机与摇镜共同完成剪辑功能。

## 20.6 主观的与修饰过的主观推轨

- 此前多是中立观察者。  
- **纯主观**：角色眼睛。  
- **修饰主观**：保主观动机，但构图更可读、更电影化（图 20-1~20-3）。
- 版本一：完全主观地向沙滩上的妻子和妹妹推进，通常由前一镜男人注视建立。
- 版本二：镜头推进时把男人也纳入画面；随着摄影机靠近他的手臂，客观观察逐渐变成修饰主观。
- 版本三：男人与摄影机同向走到坡边，人物仿佛进入自己的主观镜头；摄影机停下、男人下坡加入女人后，镜头又回到客观模式。

## 理解示例（书中案例）

1. **设计一～三：直轨建构单位（示图 20.1–20.4）**  
   - **书中例子**：侧面三种距离距不变≈可移动固定构图；两端灰区可走近/远离；可结合正面全景+侧面中景。  
   - **帮助理解**：先把推轨拆成**建构单位**再组合。

2. **设计六 vs 设计七（示图 20.8–20.9）——问答策略**  
   - **书中例子**：设计六从人物特写斜远展开后景（如火后工厂），逼观众透过人物感受空间；设计七先远景环境再让人物入特写，观众先自有判断再对照人物反应。  
   - **帮助理解**：同样一场灾难地，**先人后地 / 先地后人**给出完全不同的叙事态度。

3. **反向推轨与障碍（示图 20.11–20.15）**  
   - **书中例子**：人机相向路径使脸先朝机后背机，渐进越轴不明显；柱子等障碍应合作利用。  
   - **帮助理解**：路径设计可软化轴线问题，并与场地智取而非硬刚。
