来源：`txt/by-chapter/35-附录-摄影角度效果图/PDF第362页.txt` 至 `txt/by-chapter/35-附录-摄影角度效果图/PDF第384页.txt`（PDF第362页–PDF第384页）。图1～42和末尾视角表已对照 PDF；实际制图必须结合原图，不能只按文字想象几何位置。

## 本章定位

把平面图和立面图转换成“某机位、某镜头、某画幅实际会看见什么”的两点透视预演；也能从照片反推场地平面与近似焦距。

## 一句话概要

先建立摄影机机位 SP、中心线 CL、影像平面 PP、地平线、地线和画幅，再用三步法分别转移宽度、触地点和真实高度；反向投射则从消失点和地平线倒推摄影机与平面图。

## 原理、适用范围与限制

- 方法由美工师哈罗德·米切尔森设计，经美术设计师卡米尔·阿博特传授给作者。
- 摄影角度效果图以线性透视为基础：现实中的平行线在图上向同一消失点汇聚；线条汇聚程度与镜头焦距/视角有关。
- 远摄视角窄，消失点夹角较小；广角视角宽，线条汇聚更强。摄影角度必须同时绑定焦距和银幕宽高比。
- 输入材料是按比例绘制的场景平面图与立面图，或实景测量所得图纸。
- 摄影机俯仰不超过地平面约25°～30°时，两点透视通常够用；极高/极低角度需三点透视，本附录不教完整三点程序，作者建议向业界美工或美术设计师学习。

## 工具

- 直角三角板、半圆规、描图纸、图钉、直尺；最好使用建筑师刻度尺。
- 铅笔、圆规/分规，用于转移距离。
- 布景平面图、立面图和末尾镜头视角表。
- 厚画板，用来固定图纸并在 SP 处插图钉作为所有射线基点。

## 准备摄影角度与投射景框（图2～7）

### 1. 确定焦距和画幅

- 示例场地是狭小室内，希望看到房间大部分，因此选择25mm广角和1.85:1画幅。
- 示例角度纸外侧实线表示约47°水平视角，内侧虚线表示约27°垂直视角；末尾查表给出的25mm/1.85近似值为48°×26°，差异来自图示取整。

### 2. 建立关键线点

| 符号 | 含义 | 用途 |
| --- | --- | --- |
| SP | Station Point，摄影机机位 | 所有视线射线的起点 |
| CL | Center Line，中心线 | 画面宽度中心；在平面图上作为左右距离基准 |
| PP/BD | Picture Plane，影像平面 | 与CL垂直；代表要绘制的透视景观平面 |
| FG | Horizon，地平线 | 观者眼睛/摄影机高度；示例为离地4英尺 |
| HI | 垂直中线 | 在投射景框中平分画面宽度 |
| Ground line | 地线 | 与CL平行，用来寻找门、桌、人等触地位置 |

### 3. 固定角度纸与图纸

- 把平面图和立面图固定在厚板上；角度纸覆盖平面图，移动到视野包含需要拍摄的布景。
- 在SP处钉图钉，方便直尺围绕摄影机机位旋转。
- 立面图也画一条与摄影机高度一致的地平线。地线放在距CL等于摄影机高度换算距离的位置。

## 正向投射三步法

### 步骤一：决定左右宽度，转移距离 J（图8～9）

1. 先选一个有意义的墙角，通常从房间角落开始，以建立整体方向。
2. 用直尺从SP连接该墙角，延伸到PP。
3. 测量PP上交点到CL的水平距离，记为J。
4. 用圆规把J转移到投射景框中，从垂直中线向同一侧量取，画出墙角的垂直定位线。

原理：平面图上的摄影角度PP与最终投射景框来自同一视角，因此CL左右的点会落到景框相同左右位置。

### 步骤二：决定对象触地高度，转移距离 K/L（图10～16）

1. 用直角三角板一边对齐CL，使另一边通过平面图中的墙角。
2. 标出三角板与地线的交点。
3. 用直尺从这个地线点连接SP，延伸到PP。
4. 测量PP交点到CL的距离，记为K；把K从投射景框地平线向下转移。
5. K与步骤一的墙角垂直定位线相交，即墙角与地板相交点。

寻找同一墙面第二个触地点时，可选墙与摄影角度边缘相交之处：因为角度宽度线就是投射景框边缘，该点无需再做步骤一，直接执行步骤二并得到L。连接两个墙脚点，延长到地平线，即得该墙消失点。

### 消失点快捷方式（图19）

- 从SP分别画与两面墙平行的线；它们与延长PP的交点，就是两组墙线的消失点。
- 这个方法适用于墙、桌等直角结构，但前提是平面图方向和比例可靠。

### 步骤三：把真实高度投射到图中（图20～25）

1. 示例摄影机高4英尺，因此任一地板点到地平线的垂直距离代表4英尺。
2. 把这段距离四等分，得到该位置透视缩短后的1英尺单位；可向地平线上下继续量取。
3. 为避免逐格等分耗时，选一把刻度略大于目标距离的建筑师尺，斜放到四个刻度刚好覆盖地板—地平线距离，再沿斜尺读取等分。
4. 查立面图真实高度：示例桌高2英尺、门高8英尺、墙顶9英尺。
5. 在已定位垂线上标出高度，再把高度点连接相应消失点；同一墙面上的门窗会自动遵循透视缩短。

### 墙、门、窗的完成顺序（图23～26）

- 先用两面墙顶点和各自消失点建立天花板—墙角。
- 门窗的左右位置仍由步骤一从平面图转移；它们落在已建立墙面上，因此底部不必重复完整步骤二。
- 窗底、窗顶等高度只需在一侧按步骤三确定，再连消失点即可得到另一侧。

## 桌子完整复核案例（图27～31）

1. 对四只桌脚分别执行步骤一，确定其左右位置。
2. 执行步骤二，确定各桌脚触地位置。
3. 连接桌脚地面线，寻找桌子自身的消失点。
4. 查立面图得桌高2英尺，用步骤三在一只桌脚上标出桌面高度，再连接消失点建立后端桌面点。
5. 对另一方向重复。因为桌子与墙不平行，它必须有独立于墙面的另一组消失点。
6. 连接全部桌面点，完成体块；门框、窗框和家具细节可从平立面按比例精确转移，也可在基本几何可靠后作满足导演预演需要的估测。

最终图31是25mm镜头下的房间效果图。方法的目标是准确预览机位和搭景范围，不是把每个装饰细节都画成施工图。

## 反向投射：从照片重建平面图（图32～42）

### 1. 找地平线和摄影机机位

1. 把比照片更大的描图纸覆盖在照片上。
2. 延长天花板线、地板线等平行边，找到左右消失点；连接二点得到地平线，也是影像平面。
3. 在照片中心画垂直中心线并向下延伸。
4. 用大型直角三角板让两直角边分别通过两个消失点，直角顶点落在中心线上；顶点即摄影机SP，用图钉固定。

### 2. 建立地线和比例

- 若知道摄影机高度，按比例把地线放在距中心线对应位置；若照片来源未知，只能根据视平高度估算。原例估计约4英尺。
- 可自定绘图比例，例如1/16英寸代表1英尺，则4英尺对应1/4英寸地线距离。

### 3. 反向转移墙角

1. 从照片量墙角地面点到地平线的垂直距离A，并把A转到地平线上。
2. 从SP连接该新点，标出与地线交点。
3. 另从SP连接照片墙角在地平线上的投影，得到宽度射线。
4. 用直角三角板通过地线高度点，与宽度射线相交；交点即平面图中的墙角。
5. 在墙角放三角板，使两边分别平行于SP到左右消失点的线，即可恢复两面墙方向。

### 4. 门窗、尺度与焦距

- 从SP连接照片中门窗边缘与地平线相交处，把射线投到平面图墙线上，得到门窗位置。
- 常见门宽约30英寸，可作为估算照片空间比例的参照，再推家具和窗户尺寸；这是估测，不替代实测。
- 从SP连接照片左右边缘与地平线交点，量得水平视角。原例约40°。
- 原照片比例约1.444，不是标准电影画幅；裁成1.85后查表，30mm水平视角39.5°，最接近40°，因此可用约30mm复制相近透视。
