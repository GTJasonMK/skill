## 1. 常用术语速查

| 术语 | 工作定义 | 审计提醒 |
| --- | --- | --- |
| blocking / 走位 | 演员、主要道具及摄影机的空间动作安排 | 不把无动机走动当“丰富调度” |
| mise-en-scène / 场面调度 | 拍摄时对场景、人物、动作和画面空间的组织 | 与后期剪辑空间区分 |
| master / 主镜头 | 能连续描述人物关系和主要戏剧动作的镜头 | 不一定宽、静或全场一条 |
| coverage / 备用覆盖 | 为编辑提供反应、单人、切出、动作接点等材料 | 核算机位和排练机会成本 |
| setup / 机位设定 | 角度、景别、摄影机和调度的一组拍摄条件 | take 是同一 setup 的一次拍摄 |
| OTS / 过肩 | 以前景头肩框取对面人物 | 检查视线、肩位和基本观看方向 |
| sightline / 视线 | 人物与注视对象的想象连线 | 视线匹配是空间与认同工具 |
| cutaway / 切出 | 离开主动作的相关细节/地点 | 可缓冲但不能掩盖根本空间故障 |
| insert / 插入 | 场景内重要细节的近镜 | 明确是信息、动作接点还是强调 |
| establishing / 交代 | 建立地点、气氛或对象关系 | 不一定必须先给远景 |
| reaction / 反应 | 显示倾听者或承受者的反应 | 可用身体、物件或空间，不限面部 |
| tracking / traveling | 摄影机机位真实位移 | 与只旋转的摇镜、只变视角的变焦区分 |
| countermove | 摄影机与移动主体反向运动 | 不等于倒放或普通后拉 |
| deep focus / 深焦 | 前后较大距离范围同时足够清晰 | 与纵深调度不等同 |
| depth of field / 景深 | 焦点前后仍可接受清晰的范围 | 受格式、焦距、光圈、距离等共同影响 |
| open / closed form | 画框外延续感 / 画框内自足秩序 | 不是现实/虚假或好/坏二分 |
| POV / subjective | 代表或贴近角色所见/所感 | 视点由镜头链累积，不是一个镜头标签 |
| sequence shot | 以连续人机运动取代多个剪辑单位的段落镜头 | 必须有关键构图、焦点与降级方案 |
| montage | 欧洲：剪辑；苏联：联想/冲突；美式：浓缩段落 | 使用前声明语境 |
| zoom | 机位不变改变焦距/视角 | 与推轨的透视变化不同 |
| canted frame / Dutch angle / 倾斜画面、荷兰角 | 画框水平与地平线不平行 | 不套用“倾斜=疯狂”；说明上下文、倾斜变化与回正逻辑 |
| jump cut / 跳接 | 可见地省略连续动作或真实时间 | 区分有意压缩与意外连续性故障 |
| swish / zip / flash pan / 甩摇、快速摇镜 | 运动阶段故意模糊的快速摇镜 | 仍须设计触发、方向、声音和可读落幅 |
| locked-off / 锁定摄影机 | 摄影机在拍摄中保持固定 | 固定不等于被动；人物、声音和画内关系仍可变化 |
| follow focus / 跟焦 | 随主体距离或注意中心改变焦点 | 标记焦点接力、测距与排练，不把浅景深当自动强调 |
| off camera / off screen / 画外 | 声音或动作来自当前画框外 | 区分画外空间已建立、未知或故意误导 |

完整50余词条见内置 [重要词汇笔记](../source/notes/36-重要词汇.md)，PDF 385–389页。

## 3. 摄影角度效果图

适用：从按比例平面/立面图预览特定机位和画幅，或从照片近似反推平面与镜头视角。

### 符号

- SP：摄影机机位，所有射线基点；
- CL：平面图中心线；
- PP/BD：影像平面；
- FG：地平线/摄影机高度；
- HI：投射画面的垂直中线；
- Ground line：转移触地点与比例的地线。

### 正向投射

1. 步骤一 J：SP 连目标点到 PP，测 PP 到 CL 距离并转到画框，解决左右位置。
2. 步骤二 K/L：用地线与 SP 的转移求目标触地高度，解决物体落地位置。
3. 步骤三：用摄影机高度建立真实比例，把桌、门、墙等实际高度投射到透视图。

墙面平行线汇聚到同一消失点；与墙不平行的桌子要有独立消失点。示例摄影机高4英尺，桌高2英尺、门高8英尺、墙顶9英尺，使用25mm、1.85画幅。

摄影机俯仰不超过地平面约25°–30°时两点透视通常可用；极高/低角度需要三点透视，本附录未给完整程序。

### 反向投射

从照片延长平行边找左右消失点与地平线；用直角关系在中心线上求SP；以已知摄影机高度或估值设地线，再反向转移墙角、门窗和尺度。原书用常见门宽约30英寸估比例，并由约40°水平视角推得1.85裁幅下约30mm接近原照片。

估值必须标明，不能冒充实测或施工精度。

## 4. 原书时间与尺度参数

- 故事板会议略图：每格约1–3分钟；大型故事板排期可3–4个月甚至近一年。
- 动作出画后的空镜：通常约1–2秒；示图以约24格或更长表示；一种入点法至少约1秒空镜。
- 普通叠化：常约0.5秒，即10–12格；极短叠化/soft cut约1–10格；表现性叠化可超过1分钟。
- 多人理论穷举：五人约27镜头组合，仅用于说明必须合并简化。
- 远摄模拟群众：约10–15名群演在适当层次运动可形成更大规模感。
- 运动调度示例：countermove约推4英尺；野餐桌约15英尺轨道；游艇—船梯—码头约20英尺路径。
- 反向投射估算门宽：约30英寸；必须标为经验参照。

胶片“格”应用到24/25/30/其他帧率时先换算时间；不要机械复制格数。

## 5. 画幅与历史系统

- 默片主流约1.33:1；有声学院标准实际约1.37:1。
- 原书常见：欧洲1.66/1.75，美国1.85，70mm约2.2，变形宽银幕约2.35。
- Showscan：65mm拍摄、70mm拷贝、60fps、六轨声，目标是亮度、减少闪烁和声音动态。
- IMAX：65mm横向输片，每格15齿孔，画面约2×2.75英寸；OMNIMAX面向半球银幕。
- Iwerks历史系统可24或30fps并配六轨声。
- 原书电视/pan-and-scan和最坏约40%边缘损失属于当时语境。

宽高比不等于完整制式。当前项目另核查分辨率、传感器模式、DCP/平台容器、字幕图形安全区、变形去挤压和多版本裁切。
