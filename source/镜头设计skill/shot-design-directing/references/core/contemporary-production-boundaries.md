本文件是当代补充，不是 Steven D. Katz 原书观点。它约束 Skill 在输出“可拍摄”方案时的事实、伦理和安全边界；具体项目仍须遵守拍摄所在地法律、工会/行业规则、保险、许可与制作方制度。

## 三层标记

回答中明确区分：

- `作者原文`：书中可追溯的历史观点、方法、案例或参数；
- `Skill 提炼`：从原书跨章节整理出的镜头设计规则；
- `当代补充`：现行器材、虚拟制作、平台画幅、合规、伦理与安全要求。

任何会随年份、地区、设备、平台或制作制度变化的事实都不得静默归入作者原文。

## 必须升级的高风险内容

出现下列内容时，Skill 只描述叙事需求、画面结果、替代方案与需要确认的部门，不提供未经专业评估的具体危险操作步骤：

| 风险类别 | 至少升级给 | 镜头方案必须标记 |
| --- | --- | --- |
| 打斗、跌落、威亚、特技动作 | 特技协调、制片、安全与医疗支持 | 动作目的、替身/保护需求、可拆分替代镜头 |
| 枪械、刀具、爆破、火焰、烟雾 | 持证道具/军械、特效、安全、消防与场地 | 道具状态、隔离区、反应镜头或视效替代 |
| 车辆、船只、公共道路、高速跟拍 | 特技驾驶、交通管制、场地、保险、安全 | 车辆路径、摄影机隔离、封路/许可、低风险替代 |
| 高处、吊臂、无人机、重型运动设备 | 合格操作员、索具、安全、航空/场地许可 | 设备包络、禁入区、风/地面/载荷复核 |
| 水下、水面、恶劣天气、极端温度 | 水上/潜水安全、医疗、天气与制片 | 暴露时间、撤离条件、替代景别/视效方案 |
| 大型群众、狭窄空间、疏散受限 | 群演协调、场地、安全、医疗与安保 | 人流路径、容量、紧急出口、分层合成方案 |
| 动物 | 合格训导、福利监督、兽医与场地 | 动物行为不可完全控制、替代镜头/视效方案 |

不要因为某个危险动作在故事板中“画得出来”就把它判断为可执行。

## 受保护参与者与同意

涉及亲密场面、裸露、性内容、未成年人、创伤再现、文化或宗教敏感内容时：

- 把同意视为持续、具体且可撤回的制作条件，不从角色同意推导演员同意；
- 使用封闭场地、必要人员、明确边界和经确认的走位；
- 需要时升级给亲密协调、监护/教育岗位、心理支持、法律与制片；
- 在镜头方案中提供不依赖越界接触或暴露的替代构图、反应、声音和剪辑方案；
- 不把大特写、主观镜头或长焦偷拍感仅当作形式选择，审查其观看伦理和参与者边界。

Skill 不替代合同、同意记录、监护要求、内容告知或当地法律意见。

## 现行技术与交付规格

下列数据必须使用当前项目资料或官方文档复核：

- 摄影机传感器模式、裁切、开放门、变形倍率和镜头覆盖；
- 编解码器、色彩管理、HDR/SDR、DCP、平台容器和交付分辨率；
- 监看框线、安全区、字幕/图形区和多平台重构；
- 稳定系统、运动控制、虚拟制作、LED 墙、无人机和遥控头能力；
- 软件版本、许可、价格、地址、网站和设备可用性。

原书焦距视角表、胶片格数、MiniDV/HDV、Showscan、IMAX历史数据可用于理解方法或历史，但不得直接充当当前项目技术单。

若环境没有联网或官方文档访问能力，列出待核验的规范名称、责任部门和项目变量，明确当前不能确认；不要把本书数据、模型记忆或其他 Skill 当作现行事实替代品。

## 可执行性回答边界

使用以下判定：

- `概念上成立`：戏剧、空间、时间和视点逻辑成立；
- `有条件可拍`：已经列出场地、设备、人员、安全和测试条件，但尚未全部确认；
- `生产已确认`：只有用户提供了实际测量、测试和相关部门确认时才能使用；
- `当前无法确认`：缺关键场地、设备、人员、许可或视觉证据；
- `不应按当前方案执行`：存在未控制的高风险、同意缺口或明显不可拍条件。

不要把“概念上成立”写成“现场一定可拍”。

## 停止与降级规则

遇到下列情况，停止给出精确执行参数，转为列出需要确认的变量和低风险替代：

- 用户要求从未知场地推导精确机位距离、轨道长度、焦点或吊臂路径；
- 用户要求绕过专业协调、许可、保险、隔离或参与者同意；
- 设备能力、负载、风况、道路、水域或场地结构未确认；
- 视觉参考不足，却要求精确复刻危险动作或复杂路径；
- 用户的时间、人员和安全条件与方案直接冲突。

降级时保持戏剧命题，优先使用分段拍摄、反应镜头、画外声、遮挡、插入、较低风险景别、视效或替身方案，并把最终选择交给实际制作团队确认。
