# 视觉图版检查与升级规则

本书依赖故事板、机位图、透视图、焦距比较和画幅图。OCR 只能提供图注与邻近正文，不能恢复图形关系。

## 必须升级到 PDF 的问题

凡用户要求以下任一项，必须打开内置 [原始 PDF](../source/book.pdf) 的对应原页实际检查：

- 人物精确朝向、目光方向、左右位置或高低关系；
- 摄影机编号、轴线哪一侧、基本观看方向；
- 演员/摄影机的运动路径、箭头、起止框与遮挡点；
- 连续故事板某一格或相邻格发生的具体变化；
- 画框内手写文字、镜号、焦距、距离、尺寸或小字；
- 消失点、透视线、地平线、投射步骤和比例；
- 开放/封闭构图的精确切边、镜子和画框中画框；
- 不同焦距照片的视觉差异、主角清晰/失焦状态；
- 画幅裁切与负片面积/输片方向图。

## 检查顺序

1. 用内置 [视觉图版索引](../source/notes/00-视觉图版索引.md) 找章节、图号和教学作用。
2. 用 [来源覆盖](../core/source-coverage-map.md) 找 PDF 页段和完整章节笔记。
3. 打开 PDF 目标页，并同时检查前后1–2页的图注、编号和连续画格。
4. 区分“正文声称”“图中可见”“检查者解释”。
5. 若图像分辨率不足或标注不可读，明确说不能确认，不用 OCR 或常识补齐。

若当前环境不能打开或渲染 PDF，停止在“已定位但未视觉复核”：给出 PDF 页、图号、相邻正文和必须检查的视觉项目，不声称已经看过图。核心概念解释和文本故事板仍可继续，不要求额外 Skill。

## 不能从 OCR 推断的例子

用户问“图14-1第17格人物朝哪边”：正确响应是定位第14章图14-1并查看 PDF；仅凭 OCR 最多知道它属于37格棒球动作链，不能给左右朝向。

用户问“图10-7哪台机位越轴”：必须看图10-7的机位示意；章节文字只能解释该版本使用纵深、新轴和有意越轴。

用户问“视角表25mm是否为48°”：必须同时给画幅和水平/垂直方向；1.85原表为约48°×26°，其他画幅不同。

## 报告证据状态

使用明确措辞：

- `已查看 PDF 原图，可确认……`
- `正文/图注可确认……，但当前未检查图形，不能确认……`
- `图像标注不可辨，不能可靠判断……`

“已视觉复核”只用于实际看过目标页，不因视觉索引已登记就自动成立。

## 已知 OCR 风险

- PDF第117页存在整行缺失；不可猜补独立电影人姓名或缺句。
- 第3章《救生艇》被识别为《教生艇》，《比弗利山警探 II》出现粘连。
- 图版页文字少是正常现象，不能据此判为无知识。
- 专名、旧软件、影片名和书目正式引用须核对 PDF 字形或权威资料。
