# Decision Core

Use this first for broad or ambiguous directing tasks.

## Dancyger Decision Chain

```text
object -> candidate director's idea -> text interpretation -> actor strategy -> camera/visual strategy -> unity check -> directing level -> deliverable
```

## Core Distinctions

| Distinction | Use it to decide | Source layer |

## Operating Rules

1. Start by asking what the story is *about underneath the plot*.
2. Express the director's idea as a pressure on the main character or world: existential, relational, political, sexual, moral, historical, comic, or spiritual.
3. Test the idea against four craft channels: text interpretation, performance, camera/visual design, and editing/sound/design emphasis.
4. Treat mismatch as a diagnosis: if the camera is expressive but performance remains literal, or the performance is rich but the camera only records plot, the directing idea is weakly integrated.
5. Use case studies as precedents, not templates. A Ford strategy cannot simply be pasted onto a Breillat or Kubrick problem.
